# Deploy SAPEVO-BSC no Streamlit Cloud

1. Crie um repositorio publico no GitHub.
2. Envie estes arquivos e pastas:

```text
sapevobsc_app.py
sapevobsc/
assets/
README_SAPEVOBSC.md
DEPLOYMENT_SAPEVOBSC.md
requirements_sapevobsc.txt
requirements.txt
tests/test_sapevobsc.py
```

3. No Streamlit Cloud, selecione:

```text
Main file path: sapevobsc_app.py
```

4. Aguarde a instalacao das dependencias.

5. A aplicacao publica nao possui login nem banco de dados. Evite inserir dados sigilosos.
